1 Introducción

Este reporte realiza un análisis exploratorio de datos (EDA) del dataset Teen Mental Health. El mismo trata sobre el estado de salud mental de los adolescentes y si es consecuencia del uso de las redes sociales.

2 Importación y descripción del dataset

Descripcion general del dataset
archivo observaciones variables
Teen_Mental_Health.csv 1200 16

El dataset importado contiene 1200 observaciones y 16 variables. Cada fila representa un registro de un adolescente y cada columna describe una característica asociada al uso de redes sociales, sueño, actividad física, rendimiento académico o indicadores de salud mental.

3 Identificación de variables estadísticas

Las variables estadísticas se clasifican según el tipo de dato que representan:

  • Variables numéricas: Representan cantidades y sus valores son números sobre los que generalmente tiene sentido realizar operaciones matemáticas.
  • Variables categóricas: representan grupos, etiquetas o clases. En ellas no corresponde calcular media o cuantiles, pero sí frecuencias y moda.

Las variables categóricas describen atributos como género, plataforma más usada, nivel de interacción social, etiqueta de depresión, calidad del sueño y bandera de bienestar digital.

  • Media aritmética: suma de todos los valores dividida por la cantidad de datos.

5 Histogramas, intervalos y tablas de frecuencias

Un histograma agrupa datos numéricos continuos o discretos en intervalos de clase. Cada intervalo tiene un límite inferior y un límite superior. La amplitud es el tamaño del intervalo y la marca de clase es el punto medio. Se calcula como: marca de clase = (límite inferior + límite superior) / 2.

La tabla de frecuencias indica cuántas observaciones caen en cada intervalo:

  • Frecuencia absoluta: cantidad de datos dentro del intervalo.
  • Frecuencia relativa: proporción respecto del total.
  • Frecuencia porcentual: frecuencia relativa expresada en porcentaje.
  • Frecuencia acumulada: suma progresiva de frecuencias hasta cada intervalo.

En la construcción del histograma, las barras son adyacentes porque los intervalos representan rangos continuos. El eje horizontal muestra los intervalos de clase y el eje vertical muestra la frecuencia. Cuando los intervalos tienen la misma amplitud, la altura de cada barra permite comparar directamente la frecuencia de cada clase.

Los histogramas se construyen para las variables numéricas, ya que estas variables permiten ordenar y agrupar los datos en intervalos.

6 Diagramas de caja

Los diagramas de caja permiten observar la mediana, los cuartiles, el rango intercuartílico y posibles valores atípicos. Igual que los histogramas, se construyen para las variables numéricas.

7 Interpretación visual de los histogramas

Para interpretar un histograma se observa la forma general de la distribución:

  • Si las barras se concentran de manera similar a ambos lados del centro, la distribución es aproximadamente simétrica.
  • Si la cola se extiende hacia valores altos, se interpreta como asimetría hacia la derecha.
  • Si la cola se extiende hacia valores bajos, se interpreta como asimetría hacia la izquierda.
  • Si aparecen barras aisladas lejos del resto o puntos extremos en el diagrama de caja, puede haber datos atípicos.
